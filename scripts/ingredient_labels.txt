# Ingredient vocabulary for MobileCLIP zero-shot detection: one label per line.
# prepare_clip_assets.py turns it into app/src/main/assets/clip/label_embeddings.json:
# re-run the script after every change, the app only reads the JSON.
#
# - Labels in English: the text encoder was trained on English captions, and the
#   recipe prompts are in English too. Exception: words printed on the package, which
#   CLIP can read ("bottle of latte intero|milk", "aceto balsamico di modena").
# - "label|display": matches the specific label, shows the simple name in the app and
#   in the recipe prompts ("lactose-free milk|milk"). Visual labels ("jar of risotto
#   rice", "bocconcini mozzarella") help CLIP; display names should be plain ingredients.
# - Avoid near-synonyms of the same item: they split the softmax and can push each
#   label below the confidence threshold (22%).
# - Context helps small items ("eggs on a refrigerator shelf"), but too much context
#   turns a label into a scene match ("eggs in a refrigerator" fires on every fridge
#   crop): check that a new label scores only on crops that contain the item.
# - Only lines starting with # are comments: no inline comments.
# - Every display name needs its Italian name in ingredient_names_it.txt (shown when the
#   device language is Italian): the script stops if one is missing.
